# Security policy

## Supported versions

Only the latest release receives security fixes. The app updates itself, so make sure you are on the newest version before reporting.

## Reporting a vulnerability

Please do not open a public issue. Email **leoeligr10@gmail.com** with:

- what you found and where (app, MCP server, installer or website);
- steps to reproduce, or a proof of concept;
- the version you tested (Ajustes › Actualizaciones).

You will get a reply within 7 days. Once a fix ships, you are credited in the release notes unless you prefer otherwise.

## Scope

Finanzas stores everything in a local SQLite file and has no server or accounts. Reports about the update channel (signed `latest.json` and bundles on GitHub Releases), the bundled `finanzas-mcp` server and the installers are especially welcome.
